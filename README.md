# OVANICE

OVANICE is a free-first creative workspace. This first release provides a responsive app shell, local file selection/preview, a browser-based poster editor with PNG export, and locally saved video briefs.

## Cost and capability safeguards

- No paid AI API is configured or called.
- AI chat is intentionally disabled until a verified no-cost model/provider is selected.
- Image design currently means local poster composition, not generative AI image synthesis.
- Video generation is disabled; the workspace supports preparing and saving briefs only.
- Files are previewed in the browser and are not uploaded to a backend.
- No paid fallback, subscription, or automatic purchase is implemented.

## Deploy

Static site. No build step or runtime dependency required. Can be hosted on a free static hosting plan, subject to provider limits and terms.
