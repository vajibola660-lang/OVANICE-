To enable chat, create a Free Tier key in Google AI Studio ↗ using a project with no billing account attached. Add it in Vercel → Project → Settings → Environment Variables as GEMINI_API_KEY, then redeploy. Never put the key in GitHub or in this page. OVANICE will not subscribe to services, upgrade plans, purchase credits, or call paid APIs automatically. Any future provider integration must be checked for a genuinely free tier and must fail closed when free access is unavailable.
